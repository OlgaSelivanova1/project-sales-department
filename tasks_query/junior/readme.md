# Постановка задач

1. Посчитать выручку по месяцам.
2. Посчитать количество заказов и уникальных клиентов по дням.
3. Найти дубли клиентов по email.
4. Вывести список товаров, которые ни разу не продавались.
5. Посчитать средний чек по месяцам.
6. Найти клиентов, которые не совершали покупок последние N дней.
7. Посчитать долю каждой категории в общей выручке.
8. Вывести топ-10 клиентов по сумме покупок.
